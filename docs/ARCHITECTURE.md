# Архитектура Freelance Radar

## Текущее состояние

GitHub Pages раздаёт HTML/CSS/JS. Браузер вызывает публичные API. Серверной части, базы данных, серверного кэша и секретов нет. Это просто и бесплатно для MVP, но не подходит для безопасного хранения API-ключей, закрытых API или подсчёта откликов, которых источник не отдаёт.

## Поток данных

1. index.html загружает css/app.css и js/app.js.
2. app.js управляет интерфейсом и вызывает loadAllJobs().
3. job-service.js параллельно запускает адаптеры источников.
4. Каждый адаптер получает JSON и преобразует запись в единую модель.
5. Сервис объединяет результаты, убирает дубликаты и сортирует по дате.
6. UI показывает карточки и ссылки на оригиналы.

## Контракт будущего API

GET /api/jobs?q=&source=&remote=&page=&limit= должен возвращать items, sources, page, limit и total. В каждой вакансии должны быть id, title, company, location, remote, publishedAt, salary, tags, source, sourceUrl и responsesCount. Если число откликов недоступно, значение должно быть null.
